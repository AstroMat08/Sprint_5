# Sprint_5 - Автотесты для Stellar Burgers

## Описание
Проект содержит автоматические тесты для сервиса Stellar Burgers - космического фастфуда.

## Функциональности, покрытые тестами:
- Регистрация пользователя
- Вход в аккаунт
- Переход в личный кабинет
- Выход из аккаунта
- Раздел "Конструктор"

## Технологии:
- Python 3.10+
- Selenium WebDriver
- Pytest
